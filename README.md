## 🚀 Quick Start

### Prerequisites
- Node.js 16+ and npm

### Installation

```bash
# 1. Clone or extract the project
cd video-snapper-pro

# 2. Install dependencies
npm install

# 3. Copy files to correct locations
cp public/index.html public/index.html
cp public/manifest.json public/manifest.json
cp public/service-worker.js public/service-worker.js
cp public/offline.html public/offline.html
cp src/App.js src/App.js
cp src/App.css src/App.css

# 4. Start development server
npm start

# 5. Open browser
# http://localhost:3000
```

### Production Build
```bash
npm run build
```
